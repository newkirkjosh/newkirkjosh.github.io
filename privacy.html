Privacy Policy

This policy covers every app listed on the home page. Each is a personal Google OAuth app used only by its owner, with the owner's own Google account.

  • Each app requests only the scopes it needs, listed next to it on the home page.
  • The apps run on the owner's own computer. Google user data goes only between that computer and Google; no other server receives it.
  • No personal data is collected, stored elsewhere, sold, or shared with anyone.
  • Access can be revoked at any time at myaccount.google.com/permissions.
